# Contact Book CLI

A simple command-line interface (CLI) contact book written in Python to practice core fundamentals such as list/dictionary manipulation, functions, and error handling.

## Features

- **Add contacts:** Save a contact with name, phone number, and email.
- **List all:** View all saved contacts in an organized list.
- **Favorites:** Toggle favorite status on contacts and filter to view only starred entries (`★`).
- **Edit entries:** Update a specific field (name, phone, or email) without having to re-type the whole contact.
- **Delete contacts:** Remove entries directly by their list index.
- **Input validation:** Prevents crashes when invalid options or non-integer values are entered.
